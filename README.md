# Filament Stock

Home Assistant integration that tracks your 3D printing filament stock.

- Reads your spools from the Bambu Lab cloud (the filament list you manage in Bambu Studio).
- Reads sliced plates from a Google Drive folder and calculates how much filament each color needs.
- Shows the balance per color (stock minus needed).
- Deducts used filament automatically after each print tracked by [ha-bambulab](https://github.com/greghesp/ha-bambulab).

> Work in progress. Not ready for use yet.
