# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use [GitHub private vulnerability reporting](https://github.com/anonymouse-labs/ha-filament-stock/security/advisories/new) instead.

Never include tokens, passwords, service account keys or other secrets in a report. Describe the problem and how to reproduce it with dummy values.

## Supported versions

Only the latest release gets fixes.
